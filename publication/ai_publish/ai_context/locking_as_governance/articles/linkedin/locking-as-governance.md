If you let an assistant rewrite a tuned technical draft, you’re not editing — you’re re-authoring.

The failure mode isn’t obvious fabrication.

It’s silent dilution:

→ The constraint gets softened.

→ The proof point gets summarised away.

→ The limit disappears because it “breaks the flow”.

The post reads smoother.

It also says less.

So I use a governance state for writing:

Draft (allowed to change) → Tuned → Locked.

Once a draft is locked, updates must be surgical. No regeneration. No “improve the writing”. Just targeted edits that preserve the tuned prose.

Lesson: any tuned AI output is a fragile asset. Lock it, or you’ll delete the details that made it credible.
